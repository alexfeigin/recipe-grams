# איך מוסיפים מתכון

המתכון נשאר קריא בגיטהאב, והאתר נבנה מאותם קבצים. זהו סיכום בעברית של
[תהליך הכתיבה](../.agents/skills/recipe-grams-authoring/SKILL.md), שמחזיק את
ההוראות המלאות.

## עריכה

1. מסנכרנים את המאגר לפני העריכה ושומרים עבודה שעדיין לא הושלמה.
2. יוצרים קובצי `.MD` תואמים תחת `en/` ו־`he/`, בשם זהה, באותיות קטנות וללא
   רווחים. משתמשים בגרמים ומעדכנים את התרגום כשמשנים את התוכן. השורה הראשונה
   נשארת `[Back to Menu](../index.MD)` באנגלית ו־`[חזרה לתפריט](../index.MD)`
   בעברית; האתר מסיר אותה בזמן הבנייה. אין צורך במעטפת RTL או במטא־דאטה בתוך
   קובץ המתכון.
3. מוסיפים תמונות מותאמות לרשת תחת `public/images/`, ומקשרים משתי השפות באמצעות
   `../public/images/שם-הקובץ.jpg`. משאירים תמונות קיימות גם כשאין להן קישור, כל עוד
   אין ראיה שמצדיקה הסרה: כל התיקייה מתפרסמת באתר.
4. מעדכנים את `src/lib/recipeCatalog.ts`: כותרת ותיאור בשתי השפות, תמונה נבחרת,
   וסימונים — 🅥 רק למתכון טבעוני ו־★ רק כשהמשתמש מגדיר אותו כמועדף. משתמשים
   ב־`featuredRecipe` עם קטגוריה וסדר להצגה בעמוד הבית, או ב־`unlistedRecipe`
   עם הסבר למתכון עזר שלא רוצים להציג שם. גם מתכון שאינו מוצג בעמוד הבית
   מקבל עמוד ונכלל בחיפוש.
5. מוסיפים או מעדכנים שורה בקטגוריה המתאימה ב־`index.MD`, עם קישור לשתי השפות
   והסימונים. זהו תוכן העניינים לקוראי גיטהאב; האתר קורא את הקטלוג בנפרד.

## בדיקה ופרסום

מריצים `npm run verify` אחרי התקנת הפרויקט לפי [README](../README.md).
הפקודה בודקת, בונה מחדש כולל חיפוש, ומריצה את בדיקות הדפדפן.

לאחר האימות עושים commit ודוחפים את המקור. פרסום האתר הוא צעד נפרד: מעתיקים
את `dist/` למאגר `alexfeigin.github.io` ומפרסמים משם לפי
[תהליך הפרסום](../.agents/skills/recipe-grams-publishing/SKILL.md).
גיטהאב פייג׳ס עשוי לקחת זמן קצר להתעדכן.

המיומנויות המקושרות מחזיקות את ההוראות המחייבות. המדריך הישן ב־Word נשמר
ב[ארכיון](history/README.md).
